# Source-Wire Contracts 0.2.0 Release Candidate

Historical status: release candidate prepared locally, not yet published.

Resolution: this historical candidate shipped as
[`@source-wire/contracts@0.2.0`](https://www.npmjs.com/package/@source-wire/contracts/v/0.2.0)
and GitHub release
[`v0.2.0`](https://github.com/DanielJD1216/Source-Wire/releases/tag/v0.2.0)
from commit `180896b8ab8a0c4e587226ef79dc2ec53bbe6749`.

Source-Wire `0.2.0` is an additive contracts release candidate. It makes
`KnowledgeProvider v1` and its complete public type surface installable while
keeping the unpublished Alpha runtime outside the package.

## Additive Public Surface

The candidate adds public imports for:

- provider identity, profile, capability, and read-only boundary constants,
- search and exact-fetch request inputs,
- evidence, provenance, freshness, and sensitivity records,
- provider-bound cursors,
- gaps, safe errors, and bounded results,
- the `SourceWireKnowledgeProviderV1` interface.

Existing public contracts remain exported. This candidate does not remove or
rename the `0.1.0` public contract surface.

## Packed-Artifact Boundary

The packed candidate contains the compiled contracts, public documentation,
schemas, examples, and validation CLI. It excludes:

- `apps/alpha1-runtime`,
- PostgreSQL migrations and generated database state,
- generated conformance state,
- credentials and environment files,
- private repository paths or real data.

## External Adapter Gate

The release-candidate smoke installs the packed tarball into a clean external consumer,
implements a complete read-only `SourceWireKnowledgeProviderV1` adapter using
only package-root imports, type-checks it, and executes one synthetic
no-evidence result.

This proves that an adopter can compile an adapter against the stable package
surface. It does not prove a live connector, provider credentials, network
transport, Source-Wire runtime hosting, or production readiness.

The unpublished Alpha workspace separately proves that two synthetic adapters
can pass through the same immutable provider composition, policy, audit, and
release path. The Alpha workspace remains outside this package.

## Security Disposition

At candidate time, the known moderate MCP dependency advisory was temporarily
accepted only for Source-Wire's local, stdio-only synthetic Alpha runtime. The
current repository production dependency audit reports zero vulnerabilities,
and the disposition was recorded as resolved on 2026-08-31. Production and
hosted use remain blocked.

## Still Blocked

- live connectors remain blocked,
- production runtime remains blocked,
- hosting remains blocked,
- Windows runtime remains blocked,
- HTTP or SSE MCP remains blocked,
- static serving remains blocked,
- deployment remains blocked,
- real data remains blocked,
- automatic trusted-memory promotion remains forbidden.

## Candidate-Time No Release Mutation

At candidate time, no npm package was published.

At candidate time, no GitHub release or Git tag was created.

No deployment or hosted-service mutation occurred then or as part of this
historical record.

At candidate time, the live npm package and GitHub release were
`@source-wire/contracts@0.1.0` and `v0.1.0`. The resolution above records the
later `0.2.0` publication and release.

## Verification

Use Node.js 22 with npm from the repository root. For complete setup, read the
[Quickstart](../getting-started/quickstart.md).

```bash
npm run release:0.2.0-gate
```

This focused gate checks release metadata and blocked commands, packs the
candidate into temporary directories, inspects its file boundary, installs it
into clean temporary consumers, type-checks and executes the complete provider
contract and external-adapter surface, validates installed documentation and
examples, runs public safety and claim scans, and deletes temporary state.

It does not publish, tag, release, deploy, connect a live provider, or use real
data.

Before publication, the planned authenticated preflight command was:

```bash
npm run release:0.2.0-execution-preflight
```

At candidate time, the execution preflight verified the focused candidate gate
again, confirmed the working tree and `origin/main` were identical, required
exact-commit Package Checks to be green, required public npm access, and proved
`0.2.0`, `v0.2.0`, and the matching GitHub release were still absent. The
preflight itself performed no release mutation.
