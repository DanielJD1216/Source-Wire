# Source-Wire Contracts 0.2.0 Release

Status: published contracts package, not a hosted runtime.

Source-Wire `0.2.0` was published on 2026-07-24 as:

- npm package [`@source-wire/contracts@0.2.0`](https://www.npmjs.com/package/@source-wire/contracts/v/0.2.0),
- Git tag and GitHub release [`v0.2.0`](https://github.com/DanielJD1216/Source-Wire/releases/tag/v0.2.0),
- exact release commit `180896b8ab8a0c4e587226ef79dc2ec53bbe6749`.

## Shipped Changes

- Added the complete public `KnowledgeProvider v1` read-only contract surface.
- Added provider identity, profile, capabilities, search, exact fetch, evidence,
  provenance, freshness, sensitivity, cursors, gaps, bounds, and safe errors.
- Preserved existing `0.1.0` public contract exports.
- Proved a clean external adapter can compile and execute using package-root
  imports only.

## Known Issues And Boundaries

The known moderate MCP dependency advisory remains temporarily accepted only
for the local, stdio-only synthetic Alpha runtime. Review it no later than
2026-08-24, or immediately if dependency, transport, platform, or runtime scope
changes.

This release does not include:

- a hosted or production runtime,
- Windows runtime support,
- HTTP or SSE MCP,
- static serving,
- deployment,
- a live knowledge connector,
- real user data,
- automatic trusted-memory promotion.

Adopters bring and pay for their own knowledge base, PostgreSQL, credentials,
models, infrastructure, and agent harness.
